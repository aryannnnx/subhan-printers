📌 Overview

The order flow in Subhan Printers is a hybrid system that combines online browsing with manual WhatsApp ordering. This is because printing jobs are custom and require personal consultation.

Customer → WhatsApp → Admin → Order Created → Production → Delivered

📊 Step 8: Order Status Tracking

Status Flow:

PENDING Order Created ➜
QUOTED Quote Sent ➜
APPROVED Order Confirmed ➜
IN PRODUCTION Printing Started ➜
QUALITY CHECK Inspection ➜
READY For Delivery ➜
DELIVERED Completed

Status Descriptions:

Status Description Timeline Entry
PENDING Order created, waiting for approval "Order created"
QUOTED Price quote sent to customer "Quote sent to customer"
APPROVED Customer approved the quote "Order approved by customer"
IN PRODUCTION Printing started "Production started"
QUALITY CHECK Quality inspection "Quality check passed"
READY Ready for delivery/pickup "Order ready for pickup"
DELIVERED Delivered to customer "Order delivered"
CANCELLED Order cancelled "Order cancelled"

✅ Key Points

  • 🔹 All communication happens via WhatsApp
  • 🔹 Quotes are generated in the system
  • 🔹 Orders are created from quotes
  • 🔹 Status updates are tracked in dashboard
  • 🔹 Payments are handled offline (cash/bank transfer)
  • 🔹 Delivery can be pickup or courier
  • 🔹 Timeline shows complete order history
  • 🔹 Admin manages all orders from admin panel
