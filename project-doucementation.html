1. Project Overview

4.2 Step-by-Step Installation

Step 1: Download & Install XAMPP

Download from: https://www.apachefriends.org/

Step 2: Start XAMPP Services

1. Open XAMPP Control Panel
2. Click Start on Apache
3. Click Start on MySQL

Step 3: Clone/Copy Project

C:\xampp\htdocs\SP\

Step 4: Install Composer Dependencies

cd C:\xampp\htdocs\SP
composer require phpmailer/phpmailer firebase/php-jwt

Step 5: Configure Environment

Create .env file in project root:

APP_NAME="Subhan Printers"
APP_ENV=development
APP_DEBUG=true
APP_URL=http://localhost:8080/SP

DB_HOST=localhost
DB_NAME=subhan_printers
DB_USER=root
DB_PASS=
DB_PORT=3306

SMTP_ENABLED=false
FIREBASE_ENABLED=false

Step 6: Create Database & Import Schema

Open phpMyAdmin: http://localhost/phpmyadmin
Create database: subhan_printers
Import: database.sql

Step 7: Test Installation

Visit: http://localhost:8080/SP/

5.2 Key Table Structures

users

CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    password_hash VARCHAR(255),
    role ENUM('admin','staff','customer') DEFAULT 'customer',
    is_active TINYINT(1) DEFAULT 1,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

orders

CREATE TABLE orders (
    id INT PRIMARY KEY AUTO_INCREMENT,
    order_number VARCHAR(20) UNIQUE NOT NULL,
    user_id INT,
    customer_name VARCHAR(100) NOT NULL,
    customer_email VARCHAR(100) NOT NULL,
    customer_phone VARCHAR(20) NOT NULL,
    product_type VARCHAR(50) NOT NULL,
    quantity INT NOT NULL,
    total DECIMAL(10,2) DEFAULT 0,
    status ENUM('pending','approved','in_production','ready','delivered','cancelled') DEFAULT 'pending',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);

7. API Documentation

7.1 Authentication APIs

Login

POST /api/auth?action=login
Content-Type: application/json

Request: {"email": "user@example.com", "password": "password123"}

Response (Success):
{"success": true, "message": "Login successful", "user": {"id": 1, "name": "User"}}

Register

POST /api/auth?action=register
Content-Type: application/json

Request: {"name": "User", "email": "user@example.com", "password": "password123"}

Response (Success):
{"success": true, "message": "Registration successful!", "user": {"id": 2, "name": "User"}}

11. Authentication System

Email/Password Login Flow

  1. User enters credentials on login page
  2. Form submits to /api/auth?action=login
  3. API checks database for user
  4. Password verified using password_verify()
  5. Session created with user data
  6. User redirected to dashboard

Google Sign-In Flow

  1. User clicks "Continue with Google"
  2. Firebase popup opens
  3. User selects Google account
  4. Firebase returns ID token
  5. Token sent to /api/auth?action=firebase
  6. User created/fetched from database
  7. Session created
  8. User redirected to dashboard

Session Data

$_SESSION['user_id']      // User ID
$_SESSION['user_name']    // User name
$_SESSION['user_email']   // User email
$_SESSION['user_role']    // User role
$_SESSION['user_avatar']  // User avatar (Google)
$_SESSION['logged_in_at'] // Login timestamp

12. Features Guide

Order Flow

  1. User browses products → /order
  2. Clicks "Order Now" → WhatsApp
  3. Discusses requirements → WhatsApp chat
  4. Receives quote → Admin creates quote
  5. User approves → Admin creates order
  6. Order goes to production → Status updates
  7. Order ready → User notified
  8. Delivery/Pickup → Order completed

Quote Flow

  1. User fills form → /contact (Step 1-3)
  2. Quote request saved → Database (quotes table)
  3. Admin notified → Email
  4. Admin reviews → /admin/quotes/
  5. Admin responds → WhatsApp/Email
  6. Quote status updated → Quoted/Converted/Lost

Newsletter Flow

  1. User enters email → Newsletter form
  2. Email saved → Database (newsletter table)
  3. Welcome email sent → PHPMailer
  4. Admin manages → /admin/newsletter/
  5. Export CSV → Download subscriber list

14. Deployment Guide

Production Server Requirements

RequirementMinimum
PHP7.4+
MySQL5.7+
Apache2.4+
SSLRecommended

Deployment Steps

  1. Upload all files to server via FTP
  2. Update .env for production
  3. Set proper permissions (755 for folders, 644 for files)
  4. Import database
  5. Enable HTTPS (SSL)

Security Checklist

  • HTTPS Enabled
  • .env file secured
  • Error reporting off
  • Database backups configured
  • Strong passwords set

Backup Strategy

# Database backup
mysqldump -u root -p subhan_printers > backup_$(date +%Y%m%d).sql

# Files backup
tar -czf backup_$(date +%Y%m%d).tar.gz /var/www/html/SP/
